# FirstPay Admin Dashboard

A comprehensive admin dashboard for the FirstPay mobile wallet application.

## Features

- Modern, responsive UI built with Next.js 14 and React
- Interactive dashboard with statistics and charts
- User management
- Transaction monitoring
- KYC verification management
- Wallet management
- Analytics and reporting

## Technologies Used

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Chart.js

## Getting Started

### Prerequisites

- Node.js 16.8 or later
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/firstpay-admin-dashboard.git
cd firstpay-admin-dashboard
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Run the development server
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the dashboard.

## Building for Production

To create a production build:

```bash
npm run build
# or
yarn build
```

## Static Export

The project is configured for static exports. After building, you'll find the static files in the `out` directory:

```bash
npm run build
# or
yarn build
```

When using the static export, open the `index.html` file in the `out` directory to start.
